# Customer Management System

A simple and responsive **Customer Management System** built with **Laravel 13**, **Bootstrap 5**, and **SQLite**. This project was developed as part of a **Web Developer Internship Assessment**.

---

## ✨ Features

- Professional splash screen with smooth loading animation
- Dashboard with customer statistics
- Create, Read, Update and Delete (CRUD) operations
- Search customers
- Filter customers by status
- Pagination
- Customer details page
- Server-side validation
- Responsive Bootstrap 5 interface
- Notification system
- Profile, Settings and About pages
- Light & Dark Theme Toggle (Light Theme by Default)

---

## 🛠️ Technologies Used

- Laravel 13
- PHP 8+
- SQLite
- Bootstrap 5
- Blade Template Engine

---

## 📋 Customer Information

Each customer record contains:

- First Name
- Last Name
- Email
- Phone Number
- Address
- Status (Active / Inactive)

---

## ✅ Validation

The application includes server-side validation for:

- Required fields
- Valid email format
- Unique email addresses
- Unique phone numbers
- Phone number validation
- Input sanitization

---

## 🚀 Installation

```bash
git clone https://github.com/Santhusha1003/Customer-Management-System_WCL.git

cd Customer-Management-System_WCL

composer install

cp .env.example .env

php artisan key:generate

php artisan migrate

php artisan serve
```

> **Note:** This project uses SQLite. Ensure the `database/database.sqlite` file exists before running the migrations.

Open your browser:

```
http://127.0.0.1:8000
```
